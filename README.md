# Zayka - Zayqa Red Tomato Ketchup Website

Official website and landing page for **Zayqa Red - Premium Tomato Ketchup & Sauces**.

## 🍅 About
A modern, responsive landing page showcasing Zayqa Red's premium tomato ketchup and sauce products. Crafted with high quality visuals, interactive product highlights, nutritional details, and customer engagement sections.

## 🚀 Technologies Used
- **HTML5**
- **Tailwind CSS** (via CDN)
- **FontAwesome Icons**
- **Google Fonts (Inter)**

## 💻 How to View
Simply open `index.html` or `zayqa_red_tomato_ketchup_complete_website.html` in any modern web browser.
